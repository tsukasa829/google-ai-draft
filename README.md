# Google AI モード 下書き

Google 検索の AI モードで、日本語の長文が入力中に消えるときの回避用 Chrome 拡張です。別の入力欄で文章を作り、ボタンを押すと、全文を Google の質問欄に入れて既存の送信ボタンを押します。

## Windows の Chrome に入れる

1. このリポジトリの **Code → Download ZIP** を選び、ZIP を展開します。
2. Chrome のアドレスバーで `chrome://extensions` を開き、右上の **デベロッパー モード** をオンにします。
3. **パッケージ化されていない拡張機能を読み込む** を押し、`manifest.json` がある展開先フォルダーを選びます。
4. [Google AI モード](https://www.google.com/ai) を開きます。すでに開いている場合はページを再読み込みします。
5. 右下の **下書き** を押して入力し、変換を確定してから **AI モードに送信** を押します。

元の質問欄に別の文章があると送信を止めます。下書きはタブ内のメモリに保持され、ページの再読み込みやタブを閉じると消えます。送信先は Google の AI モードです。

## 確認範囲

Windows の Chrome 上の日本語版 Google AI モードで、同じ転送・送信処理を使った一時的な下書き欄から複数行の質問を送り、回答を確認しました。拡張としての読み込みと Windows IME での手入力は、インストール先で確認してください。
